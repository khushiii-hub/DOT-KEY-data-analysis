# Dot & Key – Skincare Sales & Customer Analytics

## Project Overview
This project focuses on analysing skincare e-commerce data to understand sales performance, customer purchasing behaviour and product trends.

## Project Objectives
- Analyse overall sales and revenue.
- Identify top-performing skincare products.
- Compare sales across product categories.
- Understand customer purchasing behaviour.
- Analyse the impact of discounts on sales.
- Generate actionable business insights.

## Tools & Technologies
- Microsoft Excel
- SQL
- Python
- Power BI
- Tableau

## Project Structure
- data/ – Dataset files
- excel/ – Data cleaning and analysis
- sql/ – SQL queries
- python/ – Python analysis
- power-bi/ – Power BI dashboards
- tableau/ – Tableau visualizations
- reports/ – Final reports and business insights

## Project Status
Currently in development.

## Disclaimer
This is an independent learning and portfolio project. It does not represent actual internal data from Dot & Key.
